📲 WhatsApp para cobranças (admin)
Número que envia cobranças/lembretes para os gestores dos restaurantes (seus clientes SaaS)
Crie uma instância separada na Evolution para não misturar cobranças com mensagens dos clientes finais. Deixe vazio para usar a instância padrão (mesma dos pedidos).
💡
Como configurar:
  1. Acesse o painel da sua Evolution API e crie uma instância nova (ex: estima-admin)
  2. Escaneie o QR Code com o WhatsApp do número que vai cobrar
  3. Digite o nome da instância no campo acima e salve
  4. Pronto — todas as cobranças e lembretes vão sair desse número
